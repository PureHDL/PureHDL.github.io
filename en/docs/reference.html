PipeHDL

Language Reference

Version: 0.1.0 | Status: Draft

PipeHDL: A pipeline-aligned hardware description language. Describe the computation — the compiler handles pipeline registers.

Philosophy

Verilog is register-centric: you first define all flip-flops, then describe the combinational logic between them. For pipelined designs, this means 70%+ of your code is boilerplate.

PipeHDL inverts this: describe the dataflow, and the compiler:

  • • Automatically inserts pipeline registers between stages
  • • Automatically generates stall/flush logic for all registers
  • • Automatically tracks valid bits through the pipeline
  • • Makes retiming trivial — change one number to change pipeline depth

Quick Example: 3-Stage Pipelined Multiplier (12 lines)

pipemul.phdl 
module pipemul #(WIDTH: u32 = 32, DEPTH: u32 = 3) (
    input clk: clock,
    input rst: reset,
    input stall: bool,
    input flush: bool,
    input a: u32,
    input b: u32,
    output out: u32,
    output valid: bool
) {
    pipe(DEPTH) {
        @0 {
            let prod = a * b;
        }

        @(DEPTH-1) {
            out = prod;
            valid = true;
        }
    }
}

To change from 3-stage to 5-stage: change DEPTH: u32 = 3 to DEPTH: u32 = 5.

The equivalent Verilog is ~80+ lines of hand-written registers, always_ff blocks, stall/flush muxes, and valid tracking.

Module Declaration

module ModuleName #(PARAM1: type = default, PARAM2: type = default) (
    direction port_name: type,
    ...
) {
    // body: pipe blocks, let statements, assignments
}

Directions: input, output, inout (default: input)

Parameters

#(WIDTH: u32 = 32, DEPTH: u32 = 3)

Types

Type Description Example

uN N-bit unsigned a: u32
sN N-bit signed val: s16
clock Clock signal clk: clock
reset Reset signal rst: reset

Pipeline Blocks

The core of PipeHDL. A pipe(DEPTH) block contains one or more @N stages:

pipe(DEPTH) {
    @0 {
        let intermediate = a + b;
    }

    @1 {
        let result = intermediate * 2;
    }

    @(DEPTH-1) {
        out = result;
    }
}

Key Semantics

  • • @N blocks contain pure combinational logic
  • • Variables defined in @N and used in @M (M > N) get M - N pipeline registers inserted automatically
  • • Variables used only within the same stage produce no registers
  • • stall freezes all pipeline registers
  • • flush clears the valid chain and resets registers

Compiler Usage

# Compile to Verilog
python -m compiler.main compile input.phdl

# Specify output file
python -m compiler.main compile input.phdl -o output.v

# Override parameters
python -m compiler.main compile input.phdl -o output.v -D DEPTH=5 -D WIDTH=16

Generated Verilog

The compiler produces clean, synthesizable, readable Verilog:

  • • Module ports map to input/output declarations
  • • Pipeline registers use reg with always_ff @(posedge clk)
  • • Stage combinational logic uses assign
  • • Valid chain is a shift register with stall/flush control
