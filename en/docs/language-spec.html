PureHDL Language Specification

Syntax Design (Draft v3)

Version: 0.2.0 Status: Draft

1. Design Principles

  1. 1
    Everything is synthesizable. No simulation-only subset.
  2. 2
    Readable at a glance. A PureHDL module should tell you what it does without scrolling through 100 lines of boilerplate.
  3. 3
    Types carry intent. Signal width, direction, clock domain — all in the type, not scattered across block boundaries.
  4. 4
    No Verilog baggage. No always, no assign, no reg/wire split, no blocking/non-blocking confusion.
  5. 5
    One assignment operator =. Context determines semantics: seq() → flip-flop, comb / module-level → combinational.
  6. 6
    Time is explicit. seq() for sequential, comb for combinational, no mixed blocks.
  7. 7
    Integration is a first-class concept. Connecting modules should feel like calling a function.
  8. 8
    Interop without inheritance. extern "verilog" for FFI, no Verilog syntax leaking into PureHDL.
  9. 9
    AI-friendly. One canonical form per concept, no redundant syntax, types carry enough information for LLMs to infer intent without context.

2. Module Declaration

counter.phdl 
module Counter #(
    Width: UInt = 8,
) (
    clk: In<Clock>,
    rst: In<Reset>,
    en:  In<Bool>,
    val: Out<UInt[Width]>,
) {
    seq(clk, rst) {
        if rst { count = 0 }
        elif en { count = count + 1 }
    }

    val = count;
}

What's gone:

  • ✓ reg — completely eliminated
  • ✓ wire — eliminated. Nothing to declare.
  • ✓ always — replaced by seq(clk, rst) for sequential logic
  • ✓ assign — replaced by direct module-level assignment val = count
  • ✓ input/output — replaced by In<T>/Out<T> in the type system

4.2 Port direction — always explicit

ports.phdl 
module Something (
    clk:  In<Clock>,           // input clock
    data: Out<UInt[32]>,       // output 32-bit
    bidir: InOut<UInt[1]>,    // inout
    a, b: In<UInt[8]>,         // two input ports, same type
)

4.3 Width inference

UInt[4] a;
UInt[4] b;
let c = a + b;      // c is UInt[5] — carry bit preserved
let d = a + b[3:0]; // d is UInt[4] — explicit truncation

4.4 Type aliases

type Address = UInt[32];

5. Combinational Logic

Simple combinational

module Add #(Width: UInt = 8) (
    a, b: In<UInt[Width]>,
    c:    Out<UInt[Width+1]>,
) {
    c = a + b;
}

Multi-statement with comb block

module Mux4 (
    sel: In<UInt[2]>,
    a, b, c, d: In<UInt[8]>,
    out: Out<UInt[8]>,
) {
    comb {
        out = case(sel) {
            0 -> a,
            1 -> b,
            2 -> c,
            _ -> d,
        }
    }
}

6. Sequential Logic

seq(clk) {
    // All assignments here infer
    // flip-flops on posedge clk
}
seq(clk, rst) {
    if rst { count = 0 }
    else   { count = count + 1 }
}
seq(clk.negedge, rst) {
    count = count + 1;
}

7. FSMs (First-class State Machines)

fsm Controller {
    state Idle, Fetch, Decode, Writeback;

    Idle -> Fetch     when start;
    Fetch -> Decode   when ready;
    Decode -> Writeback;
    Writeback -> Idle when done;
}

fsm(binary) Controller { ... }       // binary encoded
fsm(onehot) Controller { ... }       // one-hot
fsm(grey) Controller { ... }         // gray code

FSM with outputs and entry/exit actions:

fsm(onehot) Controller {
    state Idle, Fetch, Decode;

    Idle  -> Fetch when req;
    Fetch -> Decode when done;
    Decode -> Idle;

    out.busy = (state != Idle);
    out.we   = (state == Fetch);

    on_entry(Decode) {
        data_valid = true;
        cycles = 0;
    }

    on_exit(Decode) {
        data_valid = false;
    }

    on_transition(Idle -> Fetch) {
        addr_counter = 0;
    }
}

8. Interfaces

interface AXI #(AddrWidth: UInt = 32, DataWidth: UInt = 64) {
    AWID:    UInt[4];
    AWADDR:  UInt[AddrWidth];
    AWVALID: Bool;
    AWREADY: Bool;
}

Direction from usage:

module AxiMaster (
    clk: In<Clock>,
    mst: Out<AXI[32, 64]>,    // all signals are outputs
) {
    mst.AWADDR = addr;
    mst.AWVALID = valid;
}

Module integration:

module Top (clk, rst, uart_tx, uart_rx) {
    uart = new Uart(baud_rate=115200);
    dma  = new Dma();
    dma.mst = uart.slv;     // compiler checks interface compatibility
}

10. extern "verilog" FFI

extern "verilog" {
    module VerilogFifo #(Width: UInt = 8, Depth: UInt = 16) (
        clk: In<Clock>,
        din: In<UInt[Width]>,
        dout: Out<UInt[Width]>,
    );
}

module Top (clk, tx_data, rx_data) {
    let fifo = new extern VerilogFifo(Width=8, Depth=256);
    fifo.din = tx_data;
    fifo.dout = rx_data;
}

module CriticalPath (clk, a, b, c) {

        }

12. Assertions

assert count <= MAX: "Counter overflow";
assert never(count == 0 && valid);
assert always(clk): valid |-> !busy;

13. Summary: Verilog → PureHDL Departed Features

Verilog PureHDL Reason
always @(...) seq(clk, rst) / comb No sensitivity-list bugs
assign Direct assignment Redundant without reg/wire
reg / wire Automatic inference Implementation detail
blocking= / nonblocking<= Single = Eliminates biggest bug source
input/output keywords In<T>/Out<T> types Direction is a property of the type
parameter #(...) typed parameters Type safety
@(posedge clk) seq(clk) Less punctuation
SVA assert never/always Native syntax
`include use / import Module system
`ifdef / macros Generics + const eval Real code generation
generate blocks Type-safe generics + if const Not text templates
reg keyword Completely removed No justification
