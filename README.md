# PureHDL Website

Official website for [PureHDL](https://purehdl.github.io) — a modern hardware description language.

Built with [Astro](https://astro.build) + [Tailwind CSS](https://tailwindcss.com).

- 🌐 **English** → [purehdl.github.io/en/](https://purehdl.github.io/en/)
- 🌏 **中文** → [purehdl.github.io/zh/](https://purehdl.github.io/zh/)
- 🌙 **Dark mode** supported
- 📱 **Mobile responsive**

## Development

Source code: `/proj/phdl-astro/`

```bash
cd /proj/phdl-astro
npm run dev    # dev server
npm run build  # build site → dist/
```

Deploy: copy `dist/` contents to this repo's root.
