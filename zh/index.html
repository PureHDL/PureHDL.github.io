PureHDL 是一种现代硬件描述语言，从头开始构建，旨在取代 Verilog 和 SystemVerilog。类型安全、可综合，为下一个十年的芯片设计工作流程而生。

设计理念

设计理念

指导 PureHDL 每一个决策的八大支柱——从语法到编译器架构。

01

100% 可综合

模拟子集和综合子集不分家。能编译就能上芯片。语言中的每一个构造都是硬件就绪的。

02

时间在类型系统中

没有 reg 和 wire 之分。没有阻塞和非阻塞赋值之分。时间通过 seq() 和 comb 显式表达。一个赋值操作符，上下文决定语义。

03

类型安全的硬件

位宽不匹配、方向错误、组合环路——编译期捕获。In<T>/Out<T> 在类型中体现方向。无隐式截断。

04

真正的泛型

不是 Verilog 那种 parameter 的 hack。带 trait 约束的类型化泛型，像 Rust 一样。#(Width: UInt = 8)——参数级别也是类型安全的。

05

模块集成为原语

连接模块应该像调用函数一样自然。编译器检查接口兼容性。不再需要在端口列表里翻来翻去。

06

PPA 可见性

注解和类型信息让编译器在代码生成时推理时序、面积和功耗。显式声明，而非隐式产生。

07

增量编译

改一个模块 → 只重新编译那个模块。不再有数小时的全量重编译。适应现代工作流程的现代编译器。

08

AI 友好

每个概念只有一种规范形式。强类型作为隐式规格说明。从代码到硬件的确定性映射降低了 LLM 的错误率。

代码示例

60 秒看懂 PureHDL

三个示例覆盖语言核心功能。

counter.phdl 
module Counter #(Width: UInt = 8) (
  clk: In<Clock>, rst: In<Reset>,
  en: In<Bool>, val: Out<UInt[Width]>,
) {
  seq(clk, rst) {
    if rst { val = 0 }
    elif en { val = val + 1 }
  }
}
fsm.phdl 
fsm(onehot) Controller {
  state Idle, Fetch, Decode;

  Idle  -> Fetch when start;
  Fetch -> Decode when done;
  Decode -> Idle;

  out.busy = (state != Idle);

  on_entry(Decode) { data_valid = true; }
  on_exit(Decode)  { data_valid = false; }
}
extern.phdl 
extern "verilog" {
  module VerilogFifo #(Width: UInt = 8, Depth: UInt = 16) (
    clk: In<Clock>, din: In<UInt[Width]>,
    dout: Out<UInt[Width]>,
  );
}

module Top (clk: In<Clock>, tx_data: In<UInt[8]>, rx_data: Out<UInt[8]>) {
  let fifo = new VerilogFifo(Width=8);
  fifo.clk = clk;
  fifo.din = tx_data;
  fifo.dout = rx_data;
}

PureHDL vs Verilog — 对比

看 PureHDL 如何消除 Verilog 的冗长和陷阱。同样的硬件，一半的代码。

1. 计数器 — 无 reg、无 wire、无 always、无 <=

Verilog
Verilog 
// 17 行，4 个关键字
module Counter #(parameter Width = 8)
(
  input  wire       clk, rst, en,
  output reg  [Width-1:0] val
);
  always @(posedge clk or posedge rst) begin
    if (rst) val <= 0;
    else if (en) val <= val + 1;
  end
endmodule
PureHDL
PureHDL 
// 9 行，0 个新关键字
module Counter #(Width: UInt = 8) (
  clk: In<Clock>, rst: In<Reset>,
  en: In<Bool>, val: Out<UInt[Width]>,
) {
  seq(clk, rst) {
    if rst { val = 0 }
    elif en { val = val + 1 }
  }
}

2. 多路选择器 — comb 替代 always @(*) + case

Verilog
Verilog 
module Mux4 (
  input  wire [1:0] sel,
  input  wire [7:0] a, b, c, d,
  output reg  [7:0] out
);
  always @(*) begin
    case (sel)
      0: out = a;
      1: out = b;
      default: out = c;
    endcase
  end
endmodule
PureHDL
PureHDL 
module Mux4 (
  sel: In<UInt[2]>,
  a, b, c, d: In<UInt[8]>,
  out: Out<UInt[8]>,
) {
  comb {
    out = case(sel) {
      0 -> a,
      1 -> b,
      _ -> c,
    }
  }
}

3. FSM — 一等公民 vs 繁复样板

Verilog
Verilog 
// 3 个需要维护的代码块
localparam [1:0] IDLE = 0, FETCH = 1;
reg [1:0] state, next_state;

always @(posedge clk)
  state <= next_state;

always @(*) begin
  case (state)
    IDLE: next_state = FETCH;
    FETCH: next_state = IDLE;
  endcase
end

assign busy = (state != IDLE);
PureHDL
PureHDL 
// 一块搞定
fsm(onehot) Controller {
  state Idle, Fetch;

  Idle  -> Fetch when start;
  Fetch -> Idle;

  out.busy = (state != Idle);
}

Verilog 强迫你管理实现细节——reg/wire、阻塞 vs 非阻塞、敏感列表、状态编码。PureHDL 让你描述你想要什么——编译器处理其余的。更少的代码，更少的 Bug，更快的设计。
